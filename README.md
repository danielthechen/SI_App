# SI_App
An app for the Sixth Form (Year 12-13 / Grade 11-12) of Harrow HK, built by the Solutions Incubator Society. 


Features:
- Digital boaders Tuesday/Thursday signout system
- Merits/Spots system for prefects and ambassadors
- Day gym signin system for boarders
- Respective teacher interfaces to track students


Contributions (brief):

When I joined the club, the signout system was rejected by school guards and merits and spots system was very buggy in querying and didn't work very well.
I helped re-invent the signout system to accomodate the WiFi blind spot at our school's gate, which the school refused to fix. 
I also reworked the logic behind querying for a student in a list of all the school's students, so that we didn't thousands of queries for each search.


Technical Details:
- Built with Flutterflow (low-code platform)
- Custom functions written with Dart for optimized queries and data handling
- Backend powered by Firebase Firestore
- Automation workflows via Zapier and Make.com to update spreadsheets and reduce manual work.
